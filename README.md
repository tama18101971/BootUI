# CH32V003 Flasher GUI

Графический интерфейс для прошивки микроконтроллеров CH32V003 через UART.

---

## Установка

### 1. Установка Python

1. Перейдите на официальный сайт: https://www.python.org/downloads/
2. Скачайте последнюю версию Python (рекомендуется 3.10+)
3. Запустите установщик
4. **Обязательно** установите галочку **"Add Python to PATH"** на первом экране
5. Нажмите "Install Now"

### 2. Установка библиотеки pyserial

Откройте командную строку (Win + R → `cmd` → Enter) и выполните:

```
pip install pyserial
```

### 3. Проверка установки

```
python --version
pip show pyserial
```

---

## Запуск

Подключите микроконтроллер через USB-UART адаптер и выполните:

```
python bootloader_gui.py
```

---

## Использование

1. **Выбор файла** - нажмите "Browse..." и выберите файл прошивки (.bin)
2. **Выбор порта** - выберите COM-порт из списка (нажмите "Refresh" для обновления)
3. **Скорость** - установите baud rate (по умолчанию 460800)
4. **Прошивка** - нажмите "Flash Firmware"

---

## Примечания

- Перед прошивкой убедитесь, что микроконтроллер находится в режиме загрузчика.
- Закройте другие программы, использующие выбранный COM-порт
- Если порт не появляется в списке, нажмите "Refresh"
