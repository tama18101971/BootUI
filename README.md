# CH32V003 Flasher GUI

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Графический интерфейс для прошивки микроконтроллеров CH32V003 через UART.

![Скриншот программы](screenshot.jpg)

---

## Установка

### 1. Установка Python

1. Перейдите на официальный сайт: https://www.python.org/downloads/
2. Скачайте последнюю версию Python (рекомендуется 3.10+)
3. Запустите установщик
4. **Обязательно** установите галочку **"Add Python to PATH"** на первом экране
5. Нажмите "Install Now"

### 2. Установка библиотек

Откройте командную строку (Win + R → `cmd` → Enter) и выполните:

```
pip install pyserial sv-ttk
```

- **pyserial** — работа с COM-портом
- **sv-ttk** — тема Windows 11 Fluent Design (светлая/тёмная)

### 3. Проверка установки

```
python --version
pip show pyserial
```

---

## Запуск

Подключите микроконтроллер через USB-UART адаптер и выполните:

```
python bootloader_gui.py
```

---

## Использование

1. **Проверка устройства** - выберите COM-порт и нажмите "Проверить", чтобы убедиться, что плата в режиме загрузчика (зелёный индикатор = связь есть)
2. **Выбор файла** - нажмите "Обзор..." и выберите файл прошивки (.bin); шкала покажет заполнение памяти Flash
3. **Прошивка** - нажмите "Прошить"; ход процесса виден по этапам, в любой момент можно нажать "Отмена"
4. **Журнал** - цветной лог операций можно очистить, скопировать или сохранить в файл

Тема интерфейса переключается кнопкой в правом верхнем углу (по умолчанию соответствует системной теме Windows).

---

## Примечания

- Перед прошивкой убедитесь, что микроконтроллер находится в режиме загрузчика.
- Закройте другие программы, использующие выбранный COM-порт
- Если порт не появляется в списке, нажмите "Refresh"
